# Commander Staples (Reference Only)

This folder is a **personal reference library** of well-known Commander/EDH staple cards, organized by color. It exists purely as a quick lookup for the user when building or upgrading a [`Custom Decks`](../Custom%20Decks) list — it is **not** a source of truth for what's owned, and it is **not** wired into any deck-building automation or the `/generate-deck` skill.

## What's here

| File | Contents |
|---|---|
| `General Staples.md` | Broadly efficient staples that slot into almost any deck regardless of color (mana rocks, universal lands, protection, plus a handful of extremely efficient mono-colored auto-includes). |
| `White-Blue.md`, `White-Black.md`, `White-Red.md`, `White-Green.md`, `Blue-Black.md`, `Blue-Red.md`, `Blue-Green.md`, `Black-Red.md`, `Black-Green.md`, `Red-Green.md` | One file per two-color combination, covering the **gold (multicolor) staples and color-pair mana fixing** that are specific to running both of those colors together. Mono-colored staples aren't repeated across every file that includes that color — see `General Staples.md` and the note below. |

Files are named and labeled by their **colors** (e.g. "Blue-Black"), not by guild name (e.g. "Dimir"), so they're searchable without needing to know MTG guild lore.

## Important caveats

- **Not a shopping list and not a collection check.** A card appearing here says nothing about whether it's owned, reserved in a physically-assembled deck, or in a Commander precon that may or may not be available for custom builds. Always cross-reference against `moxfield_latest.csv`, `reserved_decks.md`, and `non_commander_cards.md` per the card-pool rules in `CLAUDE.md` before actually adding one of these to a deck.
- **Curated, not exhaustive.** These lists are a starting point for "what should I consider," not a complete power-ranked checklist. They'll drift out of date as new sets release — treat them as living documents to prune and extend over time.
- **Gold-focused per color pair.** The two-color files intentionally lean on multicolor cards and that pair's mana fixing (signets/lockets/cluestones, shock/check/pain lands, guildgates) rather than re-listing every mono-colored staple of each component color.
