# Archetype: Artifacts

Decks built around cheap artifacts, cost reduction, and artifact-count payoffs. Blue and Red lead; colorless does most of the work, so this fits almost any commander. Price legend: see [`../README`](../README.md). Figures without ✓ are **estimates**.
